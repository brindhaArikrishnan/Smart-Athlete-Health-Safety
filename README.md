# 🏃 Smart Athlete Health & Environmental Safety Platform

A web-based platform designed to support athlete health awareness, hydration monitoring, environmental safety, and workout wellness.

## 🌐 Live Demo

👉 [Click here to view the live website](https://brindhaarikrishnan.github.io/Smart-Athlete-Health-Safety/)

## 💻 GitHub Repository

👉 [View Source Code](https://github.com/brindhaArikrishnan/Smart-Athlete-Health-Safety)

## ✨ Features

- 💧 Health and hydration risk awareness
- 🏋️ Workout wellness and risk assessment
- 🤖 Preliminary AI skin screening prototype
- 🌤️ Environmental and workout safety awareness
- 🥗 Nutrition and recovery guidance
- 🆘 Emergency assistance information
- 👤 User profile and dashboard

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Multer

## ⚙️ Project Workflow

1. User logs into the application.
2. User enters health, workout, or environmental information.
3. The application analyzes the available inputs.
4. A risk-awareness result is displayed.
5. The user receives safety and wellness guidance.

## 🎯 Project Objective

The main objective is to bring athlete health awareness, hydration monitoring, workout safety, and environmental awareness together in one application.

## 🚀 Future Enhancements

- Live weather and UV index integration
- Wearable sensor integration
- Trained and validated AI-based image screening
- Database integration for health history
- Real-time health monitoring

## ⚠️ Disclaimer

This project is a prototype for health and safety awareness. It is not a medical diagnostic system. Users should consult qualified healthcare professionals for medical concerns.
